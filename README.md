# Kivin zapret

Отдельное приложение для Windows: Discord и YouTube работают без включённого VPN.
Ставится рядом с обычным Kivin и не мешает ему.

Скачать: раздел **Releases** справа — файл `Kivin-zapret-windows-x64-setup.exe`.

Основано на [zapret](https://github.com/bol-van/zapret) (bol-van) и способах
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (Flowseal).
